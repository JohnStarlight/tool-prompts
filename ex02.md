## Prompt: Simulate a weather API response for Paris today.

## Observation:
The unstructured prompt produces a natural language paragraph — readable but unparseable by code. The schema-bound prompt behaves like a real API endpoint: same keys, correct types, and no surrounding text regardless of the city. The model also adapts values plausibly to each location (e.g. high wind for Reykjavik, low humidity for Cairo), making it useful for mocking API responses in development and testing.
