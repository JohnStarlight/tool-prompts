# Chaining Prompts for Agent Flow

## Scenario: "What's the temperature in Paris?"

---

## Step 1 — Parse the user query

### Prompt:
A user sent this message: "What's the temperature in Paris?"
Extract the intent and parameters as JSON. Use exactly this schema and nothing else:
{"intent": string, "location": string}

### Answer:
```json
{
  "intent": "get_weather",
  "location": "Paris"
}
```

---

## Step 2 — Simulate the API call

### Prompt:
You are a weather API. Return a JSON response for the location "Paris". Use exactly this schema and nothing else:
{"location": string, "temperature_celsius": number, "condition": string, "humidity_percent": number, "wind_kph": number}

### Answer:
```json
{
  "location": "Paris",
  "temperature_celsius": 18,
  "condition": "Cloudy",
  "humidity_percent": 72,
  "wind_kph": 12
}
```

---

## Step 3 — Format the final answer

### Prompt:
You are a helpful assistant. A user asked: "What's the temperature in Paris?"
You called a weather API and got this result:
{"location": "Paris", "temperature_celsius": 18, "condition": "Cloudy", "humidity_percent": 72, "wind_kph": 12}
Write a short, friendly reply to the user based on this data.

### Answer:
It's currently 18°C and cloudy in Paris, with a humidity of 72% and light winds at 12 km/h. You might want to bring a jacket!

---

## Full Chain Test 2: "Is it hot in Cairo right now?"

### Step 1 — Parse:
```json
{
  "intent": "get_weather",
  "location": "Cairo"
}
```

### Step 2 — API response:
```json
{
  "location": "Cairo",
  "temperature_celsius": 35,
  "condition": "Sunny",
  "humidity_percent": 21,
  "wind_kph": 7
}
```

### Step 3 — Final answer:
Yes, it's quite hot in Cairo! The temperature is 35°C with clear sunny skies and very low humidity at 21%. Great beach weather, but stay hydrated!

---

## Full Chain Test 3: "Should I take an umbrella in Reykjavik?"

### Step 1 — Parse:
```json
{
  "intent": "get_weather",
  "location": "Reykjavik"
}
```

### Step 2 — API response:
```json
{
  "location": "Reykjavik",
  "temperature_celsius": 4,
  "condition": "Windy with Rain",
  "humidity_percent": 89,
  "wind_kph": 41
}
```

### Step 3 — Final answer:
Definitely bring an umbrella — and maybe a windproof one! It's 4°C in Reykjavik with heavy rain and strong winds at 41 km/h. Dress warmly.

---

## Observation:
Each prompt in the chain has a single, well-defined responsibility: the first extracts structured intent, the second produces machine-readable API data, and the third translates that data back into natural language. Because each step inputs and outputs a clear format, the chain is modular — any step can be replaced or tested independently. This is the core pattern behind tool-using agents: parse → call → respond.
